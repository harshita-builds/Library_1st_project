# 📚 Digital Library Management Web Application

A responsive, feature-rich web application built to make discovering, exploring, and accessing digital books seamless for users.

---

## 🌟 Key Features

- **Multi-Genre Digital Library:** Comprehensive collections categorized by genres including **Fiction**, **Biography**, **Humour**, **Kids**, **Technology**, and **Thriller**.
- **User Authentication:** Dedicated interfaces for user registration (`Register.html`) and login (`Login.html`).
- **Reading Assistance & Saved Books:** Features allowing users to save titles for later and access reading aid tools.
- **Interactive Portal:**
  - **Help Center:** Integrated request submission form.
  - **Feedback System:** Rating and feedback form (`feedback.html`).
  - **Policies & Services:** Transparent display of library services, reading policies, and contact information.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5 (91.8%), CSS3 (8.2%)
- **Styling Modules:** Structured stylesheets (`nav.css`, `booksection.css`)
